CSV Format Requirements

×

The CSV file must have the following columns (header row is required):

  • name (required) - Product name (max 64 characters, must be unique)
  • brand (optional) - Product brand (max 64 characters)
  • description (optional) - Product description (max 1024 characters)
  • isbn (required) - ISBN number (max 64 characters)
  • sku (required) - SKU number (max 64 characters)
  • image_url (optional) - Product image URL (max 256 characters)

Example CSV:

name,brand,description,isbn,sku,image_url
"Product 1","Brand A","Description of product 1","ISBN-001","SKU-001","https://example.com/image1.jpg"
"Product 2","Brand B","Description of product 2","ISBN-002","SKU-002","https://example.com/image2.jpg"

Tips:

  • Use the convertToCsv.sh script to convert other file formats to CSV
  • Products with duplicate names will be skipped
  • Rows with missing required fields (name, isbn, sku) will be skipped
  • Maximum file size: 100MB (configurable via MAX_FILE_SIZE environment variable)
